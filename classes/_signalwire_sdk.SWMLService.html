    ProtectedbuildSwmlForRequest

    • buildSwmlForRequest(
          _queryParams: Record<string, string>,
          _bodyParams: Record<string, unknown>,
          _headers: Record<string, string>,
          _callbackPath?: string,
      ): SwmlBuilder | null

      Service-side SWML-builder hook. Subclasses return a SwmlBuilder to fully replace the document for this request, or null to fall through to setOnRequestCallback or the static builder.

      This is distinct from the WebMixin onRequest(requestData, callbackPath) hook on AgentBase (which mirrors Python's on_request -> on_swml_request modification-merge contract). Use this hook when you want to swap the entire SWML builder; use onRequest / onSwmlRequest on AgentBase when you want to merge targeted modifications into the rendered document.

      Default implementation returns null (no-op).

      Parameters

      • _queryParams: Record<string, string>

        URL query parameters from the request.

      • _bodyParams: Record<string, unknown>

        Parsed POST body (empty object for GET requests).

      • _headers: Record<string, string>

        HTTP request headers.

      • Optional_callbackPath: string

        The callback sub-path being handled, if any.

      Returns SwmlBuilder | null

      A SwmlBuilder whose document is sent as the response, or null to delegate to the next handler in the chain.

          const P extends ToolParameters = ToolParameters,
          const R extends readonly PropertyKey[] = [],
      >(
          opts: Omit<SwaigFunctionOptions, "required" | "parameters" | "handler"> & {

                  | string

                  | FunctionResult
                  | Promise<string | Record<string, unknown> | FunctionResult>;
              parameters?: P;
              required?: R;
          },
      ): this

      Define a SWAIG function the AI can call. Tool descriptions and parameter descriptions are LLM-facing prompt engineering — see PORTING_GUIDE for guidance on writing them.

      Generic over the parameters schema (P) and required list (R): when parameters is written as a FLAT inline map ({ name: { type, … } }), the const type parameters capture its literals and the handler's args is inferred precisely — args.phone typed string, an enum prop narrowed to its literal union, required keys present and the rest optional (see ToolArgs/InferArgs). The WRAPPED JSON-Schema object ({ type:'object', properties }) and a pre-built Record are still accepted and keep the prior open-record args behavior. The args type is a compile-time authoring convenience — at runtime args is the JSON the model extracted, so the handler is the ordinary SwaigHandler.

    handleRequest

    • handleRequest(
          method: string,
          url: string,
          headers: Record<string, string>,
          body?: Record<string, unknown> | null,
      ): Promise<[number, Record<string, string>, string]>

      Framework-free request-dispatch core.

      The primitive dispatch surface the SDK ports share (mirrors Python's SWMLService.handle_request(method, url, headers, body) and, e.g., the dotnet (int, Dictionary, string) HandleRequest(...)). It performs the routing-callback check, on_request modification, and basic-auth exactly as the Hono handler path does, but over plain primitives instead of Hono Context/Response objects — so both paths produce identical responses.

      Parameters

      • method: string

        HTTP method, e.g. "GET" or "POST".

      • url: string

        The full request URL (used to derive the callback path).

      • headers: Record<string, string>

        Request headers as a plain dict.

      • Optionalbody: Record<string, unknown> | null

        The already-parsed JSON body for POST requests, or undefined.

      Returns Promise<[number, Record<string, string>, string]>

      A [status, responseHeaders, bodyString] triple. For a routing redirect the status is 307 with a Location header and an empty body; an auth failure is 401 with WWW-Authenticate: Basic; otherwise 200 with the SWML document as the body string.
