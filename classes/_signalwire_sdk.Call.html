    Class Call

    Live RELAY call with command methods.

    Don't construct directly — Call instances are created by RelayClient for inbound calls (delivered to your onCall handler) and for outbound dials.

    Each command method (answer(), play(), record(), etc.) returns when the platform acknowledges the command; event-driven completion is exposed via Action objects returned from the async "play/record/..." variants.

    Example: Inside an onCall handler

    import { RelayClient } from '@signalwire/sdk';
    const client = new RelayClient();
    client.onCall(async (call) => {
      await call.answer();
      const play = await call.play([{ type: 'tts', params: { text: 'Hello!' } }]);
      await play.wait();
      await call.hangup();
    });
