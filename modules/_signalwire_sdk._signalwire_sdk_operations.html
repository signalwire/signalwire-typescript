    Namespace @signalwire/sdk/operations

    Operations: an agent written as what it can do for a caller.

    A ServiceAgent holds operations (what it can change: cancel an order, move a booking), lookups (what it can read) and how it identifies the caller. Each operation is written once, for any caller: its fields, prepare (the rules: check, look up, build the change) and apply (one backend write). The agent runs the rest the same way for every operation: the read-back, one yes, the writes, the call's record, and a request made while another change waits.

    InfoBot (knowledge search and continuity across voice and chat) is at @signalwire/sdk/operations/infobot.
