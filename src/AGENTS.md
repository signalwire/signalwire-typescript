# The @signalwire/sdk package

This directory holds the code of the SignalWire SDK for TypeScript
(`@signalwire/sdk` on npm). In an installed package it's
`node_modules/@signalwire/sdk/dist/`, beside the docs and examples the package
ships at its root (`docs/`, `examples/`, `relay/`, `rest/`, `livewire/`).

To learn or use the SDK, run `npx sw-tsdocs`. It maps the SDK and lists the
docs and examples installed with it, and `npx sw-tsdocs api <name>` shows
signatures and JSDoc from this package's declarations. `llms.txt` in this
directory lists the same docs.

To change the SDK itself, see the AGENTS.md at the root of its repository.
